## Reflection

### GitHub Copilot
Best for small, in-editor tasks I already understood—completing functions, syntax, and short code blocks. Fast autocomplete; not my tool for multi-file or repo-wide work.

### Cursor
Best for multi-file implementation and iteration. Clear prompts plus step-by-step review worked well for Due Dates, Overdue filtering, and Tags across the Task Tracker project.

### Claude Code
Best for repo-level analysis and guided workflows—docs, structure, reviews, and planning larger updates—especially with `CLAUDE.md` and project conventions set. I still verified output with tests, diffs, and the original requirements.

### Overall
No single winner: Copilot for fast in-editor help, Cursor for controlled multi-file changes, Claude Code for repository-level guidance and larger workflows.
